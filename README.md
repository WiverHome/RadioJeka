# RadioJeka

Простое Android-приложение для прослушивания интернет-радио. Без регистрации, рекламы и лишних экранов.

- Каталог ~50 000 станций из открытой базы [Radio Browser](https://www.radio-browser.info), сортировка по популярности.
- Регион: «Россия» (по умолчанию) или «Весь мир».
- Категории: поп, рок, новости, разговорное, танцевальная, электроника, хип-хоп, ретро, шансон, джаз, классика, лаунж, метал, фолк.
- Поиск по названию с учётом выбранного региона и категории.
- Избранное, хранится на устройстве.
- Воспроизведение в фоне: управление из уведомления, с экрана блокировки и гарнитуры; пауза при отключении наушников.
- Название текущего трека, если станция его передаёт (ICY).
- Автоматическое переподключение при обрыве сети.
- Светлая и тёмная тема, цвета Material You (Android 12+).

Android 8.0+. Kotlin, Jetpack Compose, Media3 (ExoPlayer).

## Сборка

Нужны JDK 17+ и Android SDK (API 35).

```bash
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`. Release подписан debug-ключом, чтобы ставиться напрямую; для публикации в Google Play подключите свой keystore в `app/build.gradle.kts`.
