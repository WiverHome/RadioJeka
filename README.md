# RadioJeka

Простое Android-приложение для прослушивания интернет-радио. Без регистрации, рекламы и лишних экранов.

- Встроенный каталог: все российские станции и ~3 500 самых популярных в мире из открытой базы [Radio Browser](https://www.radio-browser.info). Работает без VPN и без доступа к radio-browser.info; когда сайт доступен, каталог раз в сутки обновляется, а поиск дополняется онлайн-результатами.
- Регион: «Россия» (по умолчанию) или «Весь мир».
- Категории: поп, рок, новости, разговорное, танцевальная, электроника, хип-хоп, ретро, шансон, джаз, классика, лаунж, метал, фолк.
- Поиск по названию с учётом выбранного региона и категории.
- Избранное, хранится на устройстве.
- Полноэкранный плеер (нажмите на мини-плеер): логотип, текущий трек, предыдущая/следующая станция из того списка, откуда она включена.
- Воспроизведение в фоне: управление из уведомления, с экрана блокировки и гарнитуры; пауза при отключении наушников.
- Название текущего трека, если станция его передаёт (ICY).
- Автоматическое переподключение при обрыве сети.
- Светлая и тёмная тема, цвета Material You (Android 12+).

Android 8.0+. Kotlin, Jetpack Compose, Media3 (ExoPlayer).

## Сборка

Нужны JDK 17+ и Android SDK (API 35).

```bash
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`.

Обновить встроенный каталог перед релизом (нужен доступ к radio-browser.info):

```bash
python tools/update_catalog.py
```

 Release подписан debug-ключом, чтобы ставиться напрямую; для публикации в Google Play подключите свой keystore в `app/build.gradle.kts`.
